# 商品分类沿革工作台

维护**带生效/失效日期的分类树**，可查询任意日期商品当时所属分类；分类调整（移动、拆分、合并、补录）后，
支持按**交易发生时分类（点时态口径）**或**当前分类口径**重看历史销量，并对照两种口径的差异。

零第三方依赖：仅使用 Python 3 标准库（`http.server` + `sqlite3`）与原生 HTML/JS/SVG，离线可运行。

## 快速开始

```bash
# 1. 生成跨月变更样例数据库（data/workbench.db）
python3 backend/seed.py

# 2. 启动服务（默认 http://localhost:8000）
python3 backend/server.py
# 自定义端口/库： PORT=9000 WORKBENCH_DB=/tmp/demo.db python3 backend/server.py

# 3. 运行时态规则单元测试（15 个）
python3 -m unittest discover -s tests -v
```

浏览器打开 <http://localhost:8000>。

## 五大视图

| 视图 | 能力 |
| --- | --- |
| **沿革树** | 按日期查看当时的分类树；**拖动分类卡片到新父级**完成调整（弹窗填生效日，可勾选补录）；新建/拆分/合并分类；全历史完整性校验；已停用/合并节点留档展示 |
| **时间点查询** | 选日期查看每个商品**当时**所属分类；选中商品展示完整归属版本时间线（含调整单号、类型、原因） |
| **销量双口径** | 任意日期区间内，交易时口径 vs 当前口径的分组柱状图、差异表与受影响商品明细；**下载差异明细 CSV**（带 BOM，Excel 直开） |
| **报表版本** | 已发布报表按版本留档，重述版本显示**重述原因**，旧版本标记「已替代」不被覆盖；并列展示增量重算作业 |
| **关系时间线** | 全部调整事件流 + 选中商品的归属区间甘特条 |

| 生效日 | 事件 | 演示点 |
| --- | --- | --- |
| 2026-01-01 | 初始树：电子产品/服饰/家居/茶饮/咖啡 | 1–4 月点时态报表先发布 |
| **2026-03-01** | 保温瓶 家居 → 服饰（移动） | 跨月生效，2 月与 3 月归属不同 |
| **2026-04-01** | 茶饮 + 咖啡 → 饮品（合并） | 源节点标记「已合并」并保留血缘 |

## 时态数据模型

所有关系（分类树的边、商品归属）都存为**半开区间 `[effective_from, effective_to)`**，
`effective_to IS NULL` 表示当前开放。版本行只追加、不改写：一次调整关闭旧开放行并插入新行，因此旧关系完整留档。

强制不变量（`backend/temporal_core.py`，均有单测）：

1. **无区间重叠** → 同一时点一个商品只有一个分类、一个分类只有一个父级（防「同一时点多个父级」）。
2. **无环** → 每次写边后在当日快照上做 DFS 环检测，自环/成环返回 `409` 拒绝。
3. **节点生命周期** → 分类带 `effective_from`/`retired_at`，历史快照不会出现尚未创建的分类。
4. **补录最小影响面** → `affected_scope()` 只圈定受影响商品 × 有销售且不早于生效日的月份，重算作业与报表重述严格限定在该范围。
5. **报表只追加版本** → 重述生成新版本并填写 `restate_reason`，旧版本置 `superseded` 保留。

口径解析：点时态取销售当日生效的归属区间；当前口径取商品的开放区间，开放区间缺失时沿 `lineage_mappings` 血缘追溯。

## 代码结构

```
backend/
  schema.py          SQLite 表结构（版本区间、血缘、报表版本、重算作业）
  temporal_core.py   纯函数时态核心：区间规则、树校验、时间点查询、双口径聚合、影响面计算
  operations.py      业务操作：移动/拆分/合并/补录、报表发布与重述（单事务）
  server.py          零依赖 HTTP API + 静态文件服务
  seed.py            跨月样例数据
frontend/
  index.html         单页五视图
  styles.css         明/暗双主题（色板经 dataviz 校验，CVD 安全）
  app.js             原生 JS：拖拽树、SVG 分组柱状图、时间线、弹窗、CSV 下载
tests/test_temporal.py  时态规则与业务操作单元测试
data/workbench.db        SQLite 数据库（运行 seed 后生成）
```

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/tree?date=` | 当日树快照 + 归档节点 + 全历史校验结果 |
| GET | `/api/point-in-time?date=&product_id=` | 商品当日分类 |
| GET | `/api/history?product_id=` | 商品归属版本时间线 |
| GET | `/api/lineage?category_id=` | 分类拆分/合并血缘 |
| GET | `/api/compare?from=&to=` | 双口径聚合 + 差异 + 商品明细 |
| GET | `/api/compare/export?from=&to=` | 差异明细 CSV 下载 |
| GET | `/api/reports`、`/api/jobs`、`/api/changes` | 报表版本 / 重算作业 / 调整事件 |
| POST | `/api/categories/create`、`/move`、`/split`、`/merge` | 分类调整（移动支持 `backfill`） |
| POST | `/api/products/move` | 商品移动/补录（补录自动建增量重算作业） |
| POST | `/api/reports/publish`、`/api/validate` | 发布报表版本 / 全历史树校验 |
